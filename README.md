# Watchword website

The public pages for the Watchword iPhone app, served free by GitHub Pages at
**https://nemo-435.github.io/watchword/**.

| Page | File | Used for |
|---|---|---|
| Home | `index.html` | Marketing URL in App Store Connect |
| Support | `support/index.html` | Support URL (required) |
| Privacy | `privacy/index.html` | Privacy Policy URL (required) |

All three share `style.css`. To change a page, edit its HTML here (or right on github.com
with the pencil icon) and commit. GitHub republishes within a minute or two.

The app's source lives in the private `anchor` repo; nothing here is code.
